개인정보처리방침

시행일: 2026년 10월 18일 · 적용 대상: 용인정 DART 수집기

1. 목적과 처리 범위

이 앱은 운영자 본인의 개인 연구를 위해 DART 공개 공시 자료를 수집하고 지정한 Google Drive 폴더에 전달합니다. Google Drive API를 통해 폴더 및 파일 식별자, 이름, 내용과 검증에 필요한 메타데이터를 처리합니다. 폴더 경로 확인 과정에서 상위 폴더의 메타데이터를 조회할 수 있습니다.

2. 권한과 이용

현재 OAuth 범위는 Google Drive 파일 보기·수정·생성·삭제를 허용합니다. 실제 수집 작업은 지정된 전달 폴더의 파일 업로드, 조회 및 업로드 검증을 수행합니다. 메일, 연락처, 일정 접근 권한은 요청하지 않습니다.

3. 인증 정보와 보관

OAuth 인증 토큰과 연결 설정은 사용자 PC의 rclone 설정 파일 및 사용자가 관리하는 비공개 GitHub 저장소의 Actions Secrets에 보관합니다. 이 정보는 Drive 연결 유지에 사용하며 이 안내 페이지에 게시하지 않습니다. 수집 결과는 사용자의 Drive 및 PC에 보관하며, GitHub Actions의 수집 결과·실행 기록 보관 기간은 현재 30일입니다. GitHub의 전달 완료 상태 기록은 별도 상태 브랜치에 보관합니다.

4. 제공 및 제한된 사용

Google Drive 저장에는 Google을, 클라우드 작업 실행과 비밀 설정 보관에는 GitHub를 이용합니다. Google 사용자 데이터와 인증 정보를 판매하거나 광고, 마케팅 또는 범용 AI 모델 학습에 사용하지 않습니다. Google API를 통해 받은 정보의 사용 및 다른 앱으로의 전달은 제한된 사용 요건을 포함한 Google API Services User Data Policy를 준수합니다.

5. 보유·삭제와 연결 해제

Drive에 보관한 수집 결과는 운영자가 직접 삭제할 때까지 유지합니다. 사용자는 Google 계정 연결 관리에서 앱의 접근 권한을 철회할 수 있습니다. 연결 철회만으로 기존 수집 파일이나 PC·GitHub의 설정이 삭제되지는 않으며, 설정과 저장 자료는 해당 위치에서 별도로 삭제해야 합니다.

6. 안내 웹사이트

이 안내 페이지에는 계정 로그인, 분석 추적 스크립트, 광고 또는 입력 양식이 없습니다. 웹 호스팅 제공자는 서비스 운영을 위해 접속 로그를 처리할 수 있으며, 이는 해당 제공자의 정책에 따릅니다.
